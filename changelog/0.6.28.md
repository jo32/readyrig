# 0.6.28

## Added

- **Show images in Claude Code.** The `rp` mod (0.5.0) gives Claude a `show_image` tool that draws an image from the attached project in the terminal (Ghostty, kitty), with an Open in Preview button that opens it on the Mac. On macOS, JPEG, HEIC, WebP and other formats are converted to PNG with `sips` first.
- **Call the agents on a computer.** The `readyrig-local-agents` skill (`integrations/skills/readyrig-local-agents`) shows a connected agent how to find the coding agents installed on a ReadyRig computer (Claude Code, Codex, Gemini CLI, Cursor Agent, opencode, Aider and others) with `exec_command`, report broken installs, and hand one of them a task in non-interactive mode, read-only unless the task needs edits. The skill is one self-contained file, so its text can also be pasted into a prompt.
- **Commands inherit the environment.** `exec_command` passes on the environment ReadyRig started with, as a terminal does, so a variable the platform sets for the service, such as `SEC_TOKEN_PATH` for an HDFS client, reaches the command without an `env` argument on every call. ReadyRig's own `READYRIG_*` and `RELAY_*` settings are left out. To go back to the short list (`PATH`, `HOME`, `USER` and a few others), turn off **Settings → Pass Environment** in the local console, run `readyrig env off`, or press `e` in the TUI. The choice is saved in `command-env.json`. The public console and the cloud cannot change it.

## Fixed

- **The cloud prompt works over cloud forwarding.** An agent with the cloud prompt could list a computer connected only through cloud forwarding (relay) but not call its tools: `links` was `null`, `/mcp` accepts only OAuth, and the prompt's only way forward, `tunnel.start`, turns cloud forwarding off. The prompt's key now calls tools at `POST /api/v1/computers/{id}/tools/{tool}` while `relay.state` is `connected`, with the same body and response as `links.gateway`. A computer with a tunnel link is still called at that link directly. The cloud prompt explains which address to use and says to start a tunnel only when the user agrees.
