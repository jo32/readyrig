# Unreleased

## Changed

- Plain-language menus and labels in the console, web console and website, in Chinese and English. Some names changed: **Projects** is now **Folders**, **Connection** is now **Settings**, **Desktop replay** is now **Screen Replay**, **Public** is now **Anywhere**, **Temporary link** is now **One-Time Link**, **Full access** is now **All Folders**, **Hide local paths** is now **Hide My Info** and **Cloud account** is now **Account**. Descriptions are shorter and keep the safety notes. Nothing works differently.
- The **Hide My Info** setting shows one line naming what is hidden (home folder, project folders, user name, computer name) instead of listing every token.
- **Hide My Info** is now on by default. Installs where it was turned off keep that choice.
