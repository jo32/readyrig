# 0.6.26

## Added

- **Send files between computers.** New advanced tools `receive_file` and `send_file` move a file of up to 1 GiB directly from one computer to another through a temporary quick tunnel, without the bytes passing through the agent or ReadyRig Cloud. Uploads resume after a dropped connection, the SHA-256 is checked before the file is put in place, and every open upload shares one tunnel that closes 5 minutes after the last one.
- **Receive files without a tunnel.** On a computer in relay mode, `receive_file` defaults to `via: "relay"`: ReadyRig Cloud accepts the upload at `/u/<computer>/<token>` and forwards it over the relay in 1 MiB frames, up to 100 MB per file, so `cloudflared` never runs there.
