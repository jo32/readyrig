# 0.6.30

## Changed

- **The Chrome tools no longer need Node.js.** ReadyRig used to start the Node.js program `chrome-devtools-mcp` through `npx` and pass its tools on. A Mac whose Node was only on the shell's `PATH`, or that had no Node at all, showed "Needs Setup" under Chrome connection even with remote debugging turned on in Chrome. The tools are now part of ReadyRig, written in Go, and talk to Chrome's remote debugging port directly. Nothing is downloaded on first use, and no second process runs beside the app.
- **Same tool names and arguments.** `chrome_list_pages`, `chrome_select_page`, `chrome_new_page`, `chrome_close_page`, `chrome_navigate_page`, `chrome_take_snapshot`, `chrome_take_screenshot`, `chrome_wait_for`, `chrome_click`, `chrome_hover`, `chrome_drag`, `chrome_fill`, `chrome_fill_form`, `chrome_type_text`, `chrome_press_key`, `chrome_upload_file`, `chrome_handle_dialog` and `chrome_evaluate_script` are listed; the console, network, `chrome_emulate` and `chrome_resize_page` tools stay in the `advanced` group. Their definitions take 9.9 KB of `tools/list` instead of 13.5 KB.
- **`pageId` is optional.** A tool without it uses the selected page: the one `chrome_new_page` opened or `chrome_select_page` chose. Nothing is selected at first, so a tool never acts on a tab it was not pointed at.
- **Chrome asks for permission once.** The debugging connection opens on the first tool call and is kept. A cancelled call no longer closes it, and one missed status check no longer drops it. Pausing control or turning the Chrome switch off closes it.
- **Snapshots are shorter and their `uid`s last longer.** A label's text is not repeated next to the field it names, and the `uid`s of a page's last five snapshots work until the page navigates.
- **An open dialog is reported, not waited on.** A click that opens an `alert`, `confirm` or `prompt` returns at once and says the page is blocked until `chrome_handle_dialog` answers.
- `chrome_emulate` changes only the properties passed to it; `networkConditions: "No emulation"` turns throttling off. File paths must be absolute. Console messages and network requests are recorded from the first tool call on a page.

## Removed

- `chrome_lighthouse_audit`, `chrome_performance_start_trace`, `chrome_performance_stop_trace`, `chrome_performance_analyze_insight`, `chrome_take_heapsnapshot` and `chrome_get_css_styles`. They depend on Lighthouse and the DevTools front end, which are Node.js programs.
- Cross-site iframes are no longer part of a snapshot. Same-site iframes are.
- `--chrome-mcp-command` is accepted and ignored.
