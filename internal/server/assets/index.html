设置帮助
  1. 在 Chrome 144+ 中打开 chrome://inspect/#remote-debugging，开启远程调试。
  2. 需要授权时，点击「允许访问」，选择 DevToolsActivePort 文件。

Safari 连接

等待检测

设置帮助
  1. 需要 macOS 27 和 Safari 27 或更新版本。
  2. 在 Safari 中打开「设置」，进入「开发者」标签页，勾选“Allow remote automation and external agents”（允许远程自动化和外部代理）。没有「开发者」标签页时，先在「高级」中开启“显示网页开发者功能”。
  3. 首次使用请先调用 safari_create_tab 或 safari_navigate_to_url，Safari 会打开一个受控窗口并显示横幅。

macOS 系统权限

点击「去授权」打开对应设置，允许 ReadyRig 后重新启动。通过终端启动时，请授权对应的终端应用。

链接地址

配置仅保存在本机
设置步骤
  1. 在 Cloudflare 创建一条 cloudflared 隧道，复制 Tunnel Token，粘贴到上方。
  2. 为隧道添加「已发布应用路由」，填写你的域名；服务类型选 HTTP，服务地址填 127.0.0.1:7332。这是 Agent 接口，不是管理页面。
  3. 保存配置并开启固定链接。重启 ReadyRig 后重新开启分享，完整接入地址仍保持不变。
查看 Cloudflare 配置说明 ↗

需要 Cloudflare 账号及已接入的域名。cloudflared 需为 2025.4.0 或更新版本；尚未安装时会自动下载。
