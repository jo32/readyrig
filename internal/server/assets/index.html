如何配置固定域名
  1. 在 Cloudflare 创建一条 cloudflared 隧道，复制 Tunnel Token，粘贴到上方。
  2. 为隧道添加「已发布应用路由」，填写你的域名；服务类型选 HTTP，服务地址填 127.0.0.1:7332。这是 Agent 接口，不是管理页面。
  3. 保存配置并开启固定链接。重启 ReadyRig 后重新开启分享，完整接入地址仍保持不变。
查看 Cloudflare 配置说明 ↗
